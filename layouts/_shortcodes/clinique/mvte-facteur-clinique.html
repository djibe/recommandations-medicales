• Facteur de risque majeur transitoire
    • Chirurgie sous AG ≥ 30 minutes dans les 90 jours
    • Hospitalisation pour pathologie aiguë ≥ 72 heures avec alitement dans les 90 jours
    • Césarienne dans les 90 jours
    • Fracture d’un membre inférieur dans les 90 jours
  • Facteur de risque mineur transitoire
    • Chirurgie sous AG < 30 minutes dans les 60 jours
    • Hospitalisation pour pathologie aiguë < 3 jours dans les 60 jours
    • Œstrogénothérapie (traitement hormonal ou contraceptif)
    • Grossesse ou post-partum
    • Alitement ambulatoire pour pathologie aiguë pendant ≥ 72 heures dans les 60 jours
    • Traumatisme du membre inférieur avec mobilité réduite ≥ 72 heures
  • Facteur de risque persistant
    • MICI (Crohn, RCH)
    • Cancer actif (absence de guérison)
    • Maladie auto-immune (ex. polyarthrite rhumatoïde, lupus systémique
    • Immobilité chronique
