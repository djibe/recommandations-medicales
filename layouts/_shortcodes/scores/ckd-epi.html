La formule CKD-EPI 2009 est la formule de référence pour l’estimation du débit de filtration glomérulaire (DFGe) chez l’adulte (à partir de 18 ans, en état stable) en Europe, recommandée par la HAS et l’ESC.

Cette version originale estime mieux le DFG dans les populations européennes (la variable de race n’est pas recommandée). Avant 18 ans, utiliser les formules: CKiD U25 2021, EKFC 2021 ou CKD-EPI40.

{{ $script := ` // Outil de calcul du DFG CKD-EPI 2009 by djibe // Formula ref: https://www.ncbi.nlm.nih.gov/pmc/articles/PMC8822996/ document.addEventListener('DOMContentLoaded', () => { const ageEl = document.getElementById('gfr-age'); const creatinineEl = document.getElementById('gfr-creatinine'); const gfrEl = document.getElementById('input-gfr'); const container = document.getElementById('form-gfr'); const calcGFR = () => { const unitEl = container.querySelector('input[name="gfr-unit"]:checked'); const sexEl = container.querySelector('input[name="gfr-sex"]:checked'); const ageVal = parseInt(ageEl.value, 10); let creatinineVal = parseFloat(creatinineEl.value); if (!unitEl || !sexEl || isNaN(ageVal) || isNaN(creatinineVal) || ageVal <= 0 || creatinineVal <= 0) { gfrEl.value = ''; return; } // Convert µmol/L to mg/dL (1 mg/dL = 88.4 µmol/L) const creatinine = unitEl.value === 'mol' ? creatinineVal / 88.4 : creatinineVal / 10; let alpha, beta, kappa; if (sexEl.value === 'man') { alpha = -0.411; beta = 1.0; kappa = 0.9; } else { alpha = -0.329; beta = 1.018; kappa = 0.7; } const scrOverKappa = creatinine / kappa; const minPart = Math.pow(Math.min(scrOverKappa, 1), alpha); const maxPart = Math.pow(Math.max(scrOverKappa, 1), -1.209); const agePart = Math.pow(0.9938, ageVal); const gfr = 141 * minPart * maxPart * agePart * beta; gfrEl.value = Math.round(gfr); }; container.addEventListener('input', calcGFR); container.addEventListener('change', calcGFR); });` }}
